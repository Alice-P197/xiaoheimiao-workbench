# 小黑喵工作台

Windows 桌面程序（可执行文件），暖色调黑喵主题的个人效率工作台。

## ✨ 核心功能

- 每日任务管理，按时间线排列，一目了然
- 习惯打卡，早起、读书、运动、冥想统统安排
- 日报/周报一键生成，告别加班写报告
- 项目管理看板，拖拽流转，进度清晰
- 长期目标追踪，可视化进度条超有成就感
- 支持查看过去任意一天的任务，回顾很方便

## 🎨 颜值满分

暖色调黑喵主题，配色超治愈，还有猫爪印水印和猫耳装饰，工作的时候心情都变好了～

## 💻 本地运行

数据存在本地，不用担心隐私问题，断网也能用！

## 文件与安装

- \小黑喵工作台.exe\（约 36.4 MB），下载后双击即可运行；如系统提示“未知发布者”，可在安全警告中点击“仍要运行”。
